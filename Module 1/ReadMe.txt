# jhu_software_concepts

Rachael Mends Personal Website

DESCRIPTION
-----------
This project is a personal website created using Python and Flask.
The website contains a homepage, contact page, and projects/publications page.

PROJECT STRUCTURE
-----------------
run.py
    Main entry point for the Flask application.

requirements.txt
    Contains the Python packages required to run the application.

App/
    Contains the application routes, templates, and static files.

App/routes.py
    Contains the Flask Blueprint and website routes.

App/templates/
    Contains the HTML templates for the website.

App/static/
    Contains the CSS stylesheet and profile image.


REQUIREMENTS
------------
Python 3
Flask


HOW TO RUN
----------
1. Open a terminal and navigate to the Website directory.

2. Install the required packages:

   pip install -r requirements.txt

3. Run the Flask application:

   python run.py

4. Open a web browser and go to:

   http://127.0.0.1:8080
