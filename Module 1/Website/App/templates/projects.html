Module 1 Project

This assignment teaches the fundamentals of website construction. I built a personal developer website that includes a biography, contact information/links, and details about my Python projects.

I worked with Flask, a micro web framework written in Python. I worked with HTML, and then cascading style sheets (CSS) to describe how HTML elements are to be displayed. My output is a functional personal website that includes details about me, my projects, and contact information.

Skills: Flask, HTML, Searching Methods, Data Cleaning, JSON Data Object Storage

This project was developed as part of the JHU Python Software Concepts course.
